# Transcripción de subtítulos

¡Hola developer 👋🏻! En este directorio encontrarás una guía para transcribir los subtítulos de un vídeo utilizando inteligencia artificial.

## 🎯 Objetivo

El objetivo de esta guía es mostrarte cómo puedes utilizar la inteligencia artificial para transcribir automáticamente los subtítulos de un vídeo. Esto te permitirá generar transcripciones de forma rápida y eficiente, ahorrando tiempo y esfuerzo en el proceso de creación de subtítulos.
