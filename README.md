# 🚀 Demos de la serie: IA Generativa para Devs

Este repositorio recoge las demos de mi serie en YouTube sobre IA Generativa para desarrolladores. En cada carpeta encontrarás el código mostrado en los vídeos, actualizado y con pequeñas mejoras cuando detecto errores o aparecen cambios en SDKs/APIs.

- El contenido detallado del vídeo 1 (intro y setup) ahora vive en intro/README.md.
- Cada sección enlaza al vídeo correspondiente y a su carpeta con el código.
